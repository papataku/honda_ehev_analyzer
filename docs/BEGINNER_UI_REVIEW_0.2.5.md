# 初心者視点 UI 再レビュー — 0.2.5

## レビュー方法
画面の文章、ボタン名、ボタンを押せる条件、押した後の処理、失敗時表示をコードまで照合した。以下の異なる利用者像で疑問を出した。

1. 車にもCANにも詳しくない人
2. Python/ソフトウェアは分かるが車載診断は初めての人
3. 車両整備は分かるがCAN/ELM327は初めての人
4. CAN/UDSは分かるがこのアプリは初めての人
5. PC操作に不慣れで、表示された順にボタンを押す人

## 主な疑問と確認結果
- 「最初に何を押す？」→ はじめにページで順序を固定。接続ページも ①検索→②準備テスト→③接続。
- 「準備テストは何のテスト？」→ 通信準備の検査であり車両故障診断ではないと明記。
- 「PASSしたのに、なぜまた準備テスト？」→ バグ修正。PASS後は③接続を案内する。
- 「RAW保存って何？OFFにしていい？」→ 通常ONと明記。ライブ取得中は変更不可。
- 「Startを押せない。なぜ？」→ 接続/ELM初期化の不足をライブページに表示。
- 「マーカーはいつ押す？」→ ライブ取得中だけ有効。ショートカットも同じ条件。CUSTOMキャンセル時は保存しない。
- 「ECU候補5個=車のECUは5個？」→ 違うことを常時表示。今回の要求に応答した候補だけ。
- 「ECU sourceって何？」→ ECU名ではなくCAN応答ID由来の識別値と説明。
- 「ECU確認は車に何か書く？」→ Passiveは送信なし。Activeも既知の読取りのみ。DID総当たり/書込みなし。
- 「A/Bとは？」→ A=基準、B=比較対象。グラフ選択後に明示ボタンで確定。
- 「Analyzeを押しても動かない？」→ A/B未設定では実行ボタンを無効化。0件なら理由を表示。
- 「相関を押していい？」→ field未選択では無効。相関が高くても意味確定ではないと明記。
- 「保存ZIPはどこ？」→ 保存完了メッセージを新規セッション開始表示で上書きしないよう修正。
- 「記録管理は触る必要がある？」→ 通常不要と明記。ライブ取得中は新規/終了を無効化。
- 「上級者端末は必要？」→ 通常不要。最後のタブに隔離し、安全モードを既定ON。

## 実装との照合
説明だけでなく `clicked.connect` / 実行条件 / DB保存 / ELM送信処理まで追跡した。UI文言と実処理が異なる箇所は文言ではなく実装を修正した。

## 残る前提
macOS + 実KW905での見た目（文字切れ、ウィンドウサイズ、実際のクリック感）は実機GUIで最終確認が必要。機能の回帰テストとは別の確認項目とする。
